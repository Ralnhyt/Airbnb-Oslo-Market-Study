# 🏡 Airbnb Oslo Market Study  

> **Analysis of vacation rentals on Airbnb in Oslo**  

---

## 📊 Project Overview  
This project analyzes the vacation rental market in Oslo using Airbnb data.  
The goal is to uncover pricing trends, demand patterns, and geographical distribution of properties to help hosts and travelers make smarter decisions.  

---

## 📂 Repository Structure  

| Folder / File     | Description                                               |
|-------------------|-----------------------------------------------------------|
| **Datasets/**     | Contains raw and processed data files used in the project |
| **Html/**         | Generated HTML reports and visualizations                 |
| **Notebooks/**    | Jupyter notebooks containing data cleaning, analysis & modeling |
| **Presentation/** | Final presentation slides                                 |
| **requirements.txt** | Required Python packages to reproduce the project       |
| **README.md**     | This file with all project documentation                  |

---

## 🚀 Key Analyses  
- ✅ Exploratory Data Analysis (EDA)  
- ✅ Price distribution analysis  
- ✅ Availability and seasonal trends  
- ✅ Geospatial analysis of listings  
- ✅ Price prediction modeling
